# PUBG DNS PRO V6 — Android 10+

پروژه Android Studio با داشبورد فارسی و موتور بومی WireGuard.

## قابلیت‌ها
- اجرای پنل نئونی فارسی در WebView
- انتخاب DNSهای Cloudflare، Google و Quad9 و ابزارهای تست شبکه
- انتخاب فایل کانفیگ استاندارد WireGuard با فایل‌گزین اندروید
- تجزیه کانفیگ در حافظه و عدم نمایش/ارسال کلید خصوصی به سرور برنامه
- اتصال و قطع تونل از طریق کتابخانه رسمی WireGuard Android و مجوز VPN خود اندروید
- حداقل نسخه سیستم‌عامل: Android 10 (API 29)

## نیاز ضروری برای VPN آلمان
این برنامه سرویس VPN یا سرور آلمان به همراه ندارد. برای اتصال واقعی باید فایل `.conf` معتبر از ارائه‌دهنده VPN یا سرور WireGuard خودتان داشته باشید و Endpoint آن متعلق به آلمان باشد. صرف نام‌گذاری یا انتخاب گزینه «آلمان» موقعیت سرور را تغییر نمی‌دهد. کلید خصوصی را با هیچ‌کس به اشتراک نگذارید.

## ساخت APK با Android Studio
1. پوشه `PUBG_DNS_PRO_Android` را در Android Studio باز کنید.
2. JDK 17 و Android SDK Platform 35 را نصب کنید.
3. Gradle Sync را انجام دهید.
4. از منوی Build گزینه Build APK(s) را اجرا کنید.
5. خروجی Debug در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## ساخت خودکار در GitHub Actions
محتویات این پوشه را در ریشه مخزن GitHub قرار دهید تا فایل `.github/workflows/build-apk.yml` در مسیر استاندارد قرار بگیرد؛ Workflow با `workflow_dispatch` قابل اجراست و APK را به‌صورت Artifact بارگذاری می‌کند.

## نکات فنی و امنیتی
- کتابخانه رسمی WireGuard Tunnel از Maven Central استفاده می‌شود.
- اولین اتصال، صفحه مجوز VPN استاندارد اندروید را نمایش می‌دهد.
- کانفیگ برای اتصال به موتور بومی تحویل داده می‌شود؛ برنامه کلید خصوصی را log یا به سرور خارجی ارسال نمی‌کند.
- برنامه فعلاً فایل کانفیگ را پس از بسته‌شدن برنامه نگه نمی‌دارد.
- تست‌های پینگ مرورگر، پینگ مستقیم سرور PUBG را تضمین نمی‌کنند.
- این خروجی پروژه منبع است؛ APK امضاشده Release نیست.
